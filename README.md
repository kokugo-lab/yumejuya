# 言葉の星座 ― 夢十夜 第一夜

夏目漱石『夢十夜』第一夜の授業で使うWebアプリです。生徒がGoogleフォームに書いた問一・問二の答えの言葉が、夜空の星になって浮かびます。多くの人が使った言葉は真上で大きく、一人だけが使った言葉は地平線の近くで小さく光ります。星や線をタップすると友だちの解答が読め、「ほかの人はどう読んだか」に出会えます。

- デモ（サンプル20人分）：`./?demo`
- 先生用 準備ページ：`./setup.html`

## 使い方（先生）

準備ページの手順にそって進めます（約15分）。

1. Google Apps Script のコードを実行して、フォームと回答シートを作る
2. 回答シートを「ウェブに公開」（CSV）する
3. 公開URLを貼って、学年全体・クラスごとのリンクを作る
4. 生徒にフォームのURLと自分のクラスのリンクを配る

## 公開のしかた

このリポジトリを GitHub Pages で公開すると、`index.html`（アプリ）と `setup.html`（準備ページ）がそのまま使えます。
Settings → Pages → Source を「Deploy from a branch」、Branch を `main` / `(root)` にします。
